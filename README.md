# MeshGram - ابر-اپلیکیشن ارتباطی مش و انتقال مستقیم پرسرعت 🚀

یک پلتفرم پیام‌رسان و اشتراک‌گذاری داده همه‌کاره، کاملاً آفلاین و غیرمتمرکز بر بستر شبکه مش P2P و وای‌فای دایرکت.

## ویژگی‌های شاخص:
- 🔒 **امنیت سرتاسری و رله با دانش صفر (Zero-Knowledge E2EE Relay):** پیام‌ها با ترکیب ECDH و AES-256 رمزنگاری می‌شوند و گوشی‌های واسط (رله) بدون امکان مشاهده محتوا پیام را منتقل می‌کنند.
- 🎙️ **پیام‌های صوتی با ویژوالایزر موج صدا (Waveform) و سرعت‌های 1x, 1.5x, 2x**
- 🎥 **پیام‌های ویدیویی گرد (Round Video Notes)**
- 📱 **استخراج و انتقال مستقیم فایل APK برنامه‌های نصب‌شده بدون نیاز به اینترنت**
- 📸 **استوری‌های ۲۴ ساعته همتاها با حلقه گرادینت متحرک**
- ❤️ **لایک پیام‌ها با دوبار ضربه سریع (Double-Tap to Like)**
- ⚡ **انتقال فوق سریع فایل با بافر ۲۵۶ کیلوبایت و جفت‌سازی از طریق کد QR**
- 🌓 **تم دوگانه انیمیشن‌دار (روز: زرد/سفید | شب: آبی الکتریک/مشکی عمیق اولد)**
- 🔑 **امضای اختصاصی و رسمی Release با کلید اختصاصی Keystore**
- 🛡️ **مقاوم‌سازی و مبهم‌سازی فوق‌سنگین ضد مهندسی معکوس (R8/ProGuard)**
